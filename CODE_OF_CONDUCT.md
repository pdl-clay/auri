# Código de Conduta — Contributor Covenant 2.1 (resumo local)

## Nosso compromisso

Participar deste projeto deve ser uma experiência livre de assédio para
todas as pessoas, independentemente de idade, corpo, deficiência, etnia,
identidade de gênero, nível de experiência, nacionalidade, aparência, raça,
religião ou identidade/ Orientação sexual.

## Comportamento esperado

- Demonstrar empatia e respeito.
- Aceitar feedback construtivo com gentileza.
- Assumir responsabilidade, pedir desculpas e aprender com erros.
- Focar no que é melhor para o projeto e para as pessoas.

## Comportamento inaceitável

Uso de linguagem ou imagens sexualizadas, trolling, comentários ofensivos,
assédio público ou privado, publicação de information privada sem permissão e
qualquer conduta que possa ser considerada inadequada em um ambiente
profissional.

## Aplicação

Casos de comportamento abusivo, assédio ou inaceitável podem ser reportados
aos mantenedores através de uma issue no repositório ou, quando envolverem
dados sensíveis, pelo canal privado de Security Advisories. Todas as reclamações
serão analisadas de forma justa e respeitosa; a decisão pode ir de um aviso
privado até o bloqueio permanente.

Este resumo é baseado no Contributor Covenant 2.1
(https://www.contributor-covenant.org/version/2/1/code_of_conduct/). O texto
completo da versão 2.1 se aplica a este projeto.
