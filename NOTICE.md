# Part 2 — Escopo e suporte

A MIT License acima é a licença do código. Esta segunda parte não altera a
licença; ela apenas descreve como este projeto é mantido.

Auri é uma ferramenta pessoal. O código está publicado porque pode ser útil,
não porque exista um serviço, uma comunidade ou um compromisso de suporte.
Não há SLA, roadmap vinculante nem garantia de que recursos serão mantidos
para outros casos de uso.

- Issues são bem-vindas para bugs e ideias.
- PRs são bem-vindos e serão avaliados quando houver tempo.
- Não é um produto Maestri, nem um fork, nem substituto oficial dele.
- Se algo só funciona no meu ambiente, isso é uma limitação conhecida, não um
  pedido aberto de compatibilidade.

## Part 2 — Scope and support (English)

The MIT License above governs the code. This second part does not change it;
it only describes how the project is maintained.

Auri is a personal tool. It is public because it may be useful, not because
there is a service, community, or support commitment behind it. There is no
SLA, no binding roadmap, and no guarantee that features will be maintained for
other people's use cases.

- Issues are welcome for bugs and ideas.
- Pull requests are welcome and reviewed when time allows.
- It is not a Maestri product, fork, or official replacement.
- If something only works in my environment, that is a known limitation, not
  an open compatibility request.
